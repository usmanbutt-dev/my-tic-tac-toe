# Tic-Tac-Toe, Revisited

A second browser implementation of tic-tac-toe with a randomly choosing opponent.

**[Play the demo](https://usmanbutt-dev.github.io/my-tic-tac-toe/)**

## How it works

Click a free cell to place a tick. The script removes that cell from the available-move list, waits briefly, and chooses a random remaining cell for the opponent's cross. It then compares the nine cell images across rows, columns, and diagonals.

## Run locally

Open `index.html` in a browser. It uses `script.js`, `style.css`, and the tick/cross images in `assets/`, with no build step.
